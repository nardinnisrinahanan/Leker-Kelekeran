LEKER KELEKERAN WEBSITE

Struktur folder:
- index.html: halaman utama website
- assets/css/: file tampilan website
- assets/js/: file JavaScript
- assets/img/: logo dan gambar
- assets/vendor/: library Bootstrap dan plugin pendukung

Cara menjalankan:
1. Ekstrak folder ZIP.
2. Buka folder Orbit/Orbit.
3. Jalankan index.html menggunakan browser atau buka folder tersebut melalui VS Code.

Catatan:
- main.css merupakan stylesheet utama template.
- leker-custom.css berisi penyesuaian tampilan Leker Kelekeran.
- Tautan pemesanan mengarah ke WhatsApp.
- Kritik dan saran mengarah ke profil Instagram Leker Kelekeran.
